# NOTES (read before you `pip install`):
#
# 1. Install everything in ONE `pip install -r requirements.txt` call
#    inside a clean virtual environment. The LlamaIndex ecosystem is
#    split into many fast-moving sub-packages (llama-index-core +
#    integration packages), and installing them together lets pip's
#    resolver pick a mutually compatible set instead of you pinning
#    versions by hand and hitting conflicts later.
#
# 2. Two generations of Gemini integration are used on purpose, because
#    the scripts show both. The first four scripts import from
#    `llama_index.llms.gemini` / `llama_index.embeddings.gemini`, which
#    sit on the older `google-generativeai` SDK (importing it prints a
#    FutureWarning that support for that SDK has ended). The last two
#    scripts import from `llama_index.llms.google_genai` /
#    `llama_index.embeddings.google_genai`. If you only run the last two
#    scripts, you can drop the two older integrations and
#    `google-generativeai`.
#
# 3. `sentence-transformers` pulls in PyTorch. On the first run of the
#    two agent scripts, the cross-encoder weights
#    (`cross-encoder/ms-marco-MiniLM-L-2-v2`) are downloaded from
#    Hugging Face, so an internet connection is needed at that point.
#    If you only have a CPU, you can install the CPU build of PyTorch
#    first to keep the install smaller.
#
# 4. `Memory`, `FunctionAgent`, and `ReActAgent` come from recent
#    versions of `llama-index-core`. If you hit an ImportError on
#    `llama_index.core.memory` or `llama_index.core.agent.workflow`,
#    upgrade with: `pip install --upgrade llama-index-core`
#
# 5. Everything installs from PyPI. No system binaries and no
#    git-based installs are needed.
# ------------------------------------------------------------------
